# Byte Me - Projection-Based Checkers Game

## Overview

Byte Me is a **projection-based checkers game** that allows users to play against an AI without a traditional screen. The game is designed to reduce screen time while maintaining the convenience of digital gameplay. A **projector displays the board and opponent's pieces**, while a **camera tracks the player's moves**.

## Features

- **Screenless Gameplay**: Uses projection mapping instead of a digital screen.
- **Real-Time Move Tracking**: A camera detects piece movements and validates moves.
- **AI Opponent**: Players can challenge an AI without requiring an online connection.
- **Interactive Projection**: The board and opponent pieces are dynamically projected.
- **Physical Interaction**: Players use real checker pieces instead of a touchscreen.

## How It Works

1. A **projector** displays the checkers board and opponent's pieces.
2. The **player places their own physical pieces** on the board.
3. A **camera tracks movements** and updates the game state.
4. The AI **validates moves** and responds accordingly.
5. Players can interact using a **custom keypad** instead of a PC keyboard.

## Technologies Used

- **Python**: Main programming language for logic and UI.
- **OpenCV**: Image recognition for tracking pieces.
- **Tkinter**: GUI interface for game controls.
- **Projector & Camera**: Display board and track moves.

## Future Improvements

- **Online Multiplayer Mode**: Allow remote gameplay between users.
- **Improved Tracking**: Use **QR codes** for better piece recognition.
- **Enhanced AI**: Improve opponent strategy and difficulty levels.
- **Expanded Games**: Adapt system for Chess and other board games.
